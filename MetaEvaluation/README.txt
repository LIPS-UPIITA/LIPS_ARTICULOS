This folder contains two softwares.

1. MetaAnalysis_groups_final.m
 MATLAB R2024b compatible

 Meta-analysis of Mean Differences (MD)
 Random-effects models:
   1) DerSimonian-Laird (DL)
   2) REML

 Three prespecified subgroup-specific meta-analyses:
   - Elderly_Female: k = 2
   - Elderly_Male:   k = 2
   - Elderly:        k = 4

It is an autocontent software used for meta-analysis of handgrip test for article "Electrophysiological signatures of sarcopenia: a systematic
review of sEMG features, fatigue indices and AI based classifiers"submitted to sensor MDPI


2. A R script using metafor as a VALIDATION OF MATLAB META-ANALYSIS "validation_metafor.R"

for sEMG handgrip - sarcopenia

 validation_metafor.R
 R version: 4.6.1
 Package: metafor 5.0-1

 Primary implementation:
   MATLAB R2024b
 Independent verification:
   R / metafor


3. Data requiered for meta-analysis in this paper.
inputData.xlsx

4. Folder with the results obtained with MetaAnalysis_groups_final.m
